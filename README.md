# DevTrack

DevTrack is a project management and technical learning platform designed to help developers organize projects, manage tasks, and track their learning progress.

## Goals

- Manage personal and collaborative projects.
- Organize tasks and track their progress.
- Create and follow technical learning paths.
- Track learning progress and resources.
- Explore backend engineering concepts through a real application.

## Technology Stack

- Go
- PostgreSQL
- REST API
- OpenAPI / Swagger
- Docker
